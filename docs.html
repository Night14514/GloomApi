🔍 GloomApi

Универсальное API для поиска по данным

📡 Основной Endpoint

POST /search

Все запросы отправляются на этот endpoint с JSON телом.

🔑 Аутентификация

Создание API ключа

curl -X POST http://localhost:8000/key \ -H "Content-Type: application/json" \ -d '{"name": "MyKey", "days": 30, "limit": 10000}'
Ответ: JSON с ключом для использования в запросах

📱 Поиск по телефону

curl -X POST http://localhost:8000/search \ -H "Content-Type: application/json" \ -H "Authorization: Bearer YOUR_API_KEY" \ -d '{"phone": "+79001234567"}'
phone

Номер телефона в международном формате (+79001234567)

📧 Поиск по email

curl -X POST http://localhost:8000/search \ -H "Content-Type: application/json" \ -H "Authorization: Bearer YOUR_API_KEY" \ -d '{"email": "user@mail.ru"}'
email

Email адрес пользователя

Примечание: Результат будет сохранён в указанный файл в формате JSON
